# actionator
a godot game of killing slimes and collecting apples but when you die you go back to level 1, how far can you go?

play here!! https://evmaagca.itch.io/actionatior

game made with godot and gdscript with slimes, apples and different tiles!! i created the game's levels, player systems, enemies, UI, combat mechanics, upgrades, scoring system, and achievement system using godot's scene and scripting systems. the project uses separate scripts for systems such as the player, slimes, hud, levels, achievements, and game management. i also used signals to communicate between different parts of the game, such as when the player collects an apple, dies, or unlocks an achievement. i am super proud of this game and hope to create future games with this knowlegde.

# features
- 15 levels that get progressively harder
- titlescreen buttons for credits, controls, acheivements etc
- sword combat with normal and charged attacks
- dash ability with stamina cost and temporary invincibility
- combo system for defeating enemies quickly
- health and stamina systems
- apples that increase your score and can restore health
- upgrades that improve abilities such as attack, defense, speed, and stamina
- chests and collectibles throughout levels
- slime enemies with knockback and different challenges
- run timer that tracks how quickly you progress
- best run system that records your farthest level and fastest time

# controls
WASD - move / 
space - attack / 
shift - dash / 
esc - pause

# development

```sh
git clone https://github.com/https://github.com/evacoffee/actionator.git
```


2.) go on godot


3.) click import and select the project.godot file inside the downloaded project


4.) once project opens press f5 to run game
