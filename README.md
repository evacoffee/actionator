# actionator
a godot game of killing slimes and collecting apples but when you die you go back to level 1, how far can you go?

game made with godot and gdscript with slimes, apples and different tiles!!

# development
1.) clone this repo
```sh
git clone https://github.com/https://github.com/evacoffee/actionator.git
```


2.) go on godot


3.) click import and select the project.godot file inside the downloaded project


4.) once project opens press f5 to run game
